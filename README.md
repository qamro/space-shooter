# 🚀 Neon Space Shooter


**A 2D arcade-style space shooter developed using Python and Pygame. Take control of a spaceship, dodge incoming enemies, and shoot them down to achieve the highest score in a neon-inspired space environment.**



# Running

To run the game just:

**Clone the repo** 

then:

**execute these two commands(this for activate the virtual environment and run the game):**
- source venv/venv/bin/activate                                           
- python main.py
